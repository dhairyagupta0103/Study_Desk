# Study Desk

A small, browser-based study organizer for keeping track of schoolwork and practising topics.

## Use it

Open `index.html` in a web browser. No account, server, or paid service is needed.

- Add assignments with a subject, due date, and notes.
- Open a task to turn it into a short checklist.
- Mark work complete and see this week's progress.
- Enter a topic in Study Room for a guided 20-minute practice plan and self-check questions.
- Use the focus timer when you want a quiet work session.
- Add an optional profile name shown in the page header.

Tasks, the last topic, and the optional profile name are saved automatically in this browser on this device. A saved-status label confirms changes, and open tabs refresh when the saved data changes. They do not sync to other devices and are not uploaded to an AI service. Clearing this browser's site data will erase the saved information.

## Publish it

The site is made from static files, so it can be hosted by a static website service. Upload `index.html`, `styles.css`, `app.js`, and `study-icon.svg` together; keep them in the same folder. `README.md` is for setup notes and is not needed by the site.

## Current scope

Study plans are generated from built-in prompts in the page. There is no AI connection or online account system yet, so the site does not read or solve uploaded assignments. The profile is only a name on this device; it does not use a password or email. The plan helps students practise explaining and recalling what they learned.
